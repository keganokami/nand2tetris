# Tetris - テトリス

Nand2Tetrisの集大成として作成したテトリスゲームです。
NANDゲートから構築したコンピューターシステム上で動作します。

## 操作方法

| キー | 動作 |
|------|------|
| ← | 左に移動 |
| → | 右に移動 |
| ↓ | ソフトドロップ（高速落下） |
| ↑ / Z | 時計回りに回転 |
| X | 反時計回りに回転 |
| スペース | ハードドロップ（即座に落下） |
| Q | ゲーム終了 |

## スコアリング

| 消したライン | ポイント |
|-------------|----------|
| 1ライン（シングル） | 100 × レベル |
| 2ライン（ダブル） | 300 × レベル |
| 3ライン（トリプル） | 500 × レベル |
| 4ライン（テトリス） | 800 × レベル |

**ボーナス:**
- ソフトドロップ: 1セルにつき1ポイント
- ハードドロップ: 1セルにつき2ポイント

## レベルシステム

- 10ライン消すごとにレベルアップ
- レベルが上がると落下速度が速くなる
- 最大レベル: 15

## 実行方法

### 方法1: VMエミュレータで実行（推奨）

```bash
# 1. JackCompilerでコンパイル
cd Jack/src/Tetris
JackCompiler .

# 2. VMエミュレータで実行
# Nand2Tetrisソフトウェアスイートを使用
VMEmulator
# Tetrisフォルダを開いて実行
```

### 方法2: 自作ツールチェーンで実行

```bash
# 1. JackCompilerでコンパイル（.jack → .vm）
java -cp ../../JackCompiler/bin JackCompiler .

# 2. VMTranslatorでアセンブリに変換（.vm → .asm）
java -cp ../../VM/bin VMTranslator .

# 3. Assemblerで機械語に変換（.asm → .hack）
java -cp ../../ASMBR/bin Assembler Tetris.asm

# 4. CPUエミュレータで実行
```

### 方法3: OSと統合して実行

```bash
# OSファイルをコピー
cp ../../OS/src/*.jack .

# コンパイル
JackCompiler .

# VMエミュレータで実行
```

## 実装の特徴

### テトリミノの回転
各ピースは4x4グリッドで表現され、4つの回転状態を持ちます。
壁キック機能により、壁際でも回転が可能です。

### 衝突検出
ピースの移動・回転時に、壁や床、既存ブロックとの衝突を検出します。

### ライン消去
横一列が揃うと消去され、上のブロックが落下します。
同時に複数ライン消去も対応しています。

### 乱数生成
ユーザーの入力タイミングを利用して乱数シードを更新し、
より自然なピースの出現順序を実現しています。

## 技術スタック

このテトリスは以下の自作コンポーネント上で動作します：

1. **Hackハードウェア**（プロジェクト1-5）
   - NANDゲートから構築したCPU
   - メモリマップドI/O

2. **Hackアセンブラ**（プロジェクト6）
   - アセンブリ → 機械語

3. **VMトランスレータ**（プロジェクト7-8）
   - VMコード → アセンブリ

4. **Jackコンパイラ**（プロジェクト10-11）
   - Jack言語 → VMコード

5. **Jack OS**（プロジェクト12）
   - メモリ管理、画面描画、キーボード入力
